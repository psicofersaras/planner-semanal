# Planner semanal

Herramienta gratuita de [@psicofersaras](https://www.instagram.com/psicofersaras/) para planificar la semana por bloques de color y llevarla a tu calendario (archivo .ics, compatible con Google Calendar, Apple Calendario, Outlook y otros).

Todo ocurre en tu navegador: no se envía ni se guarda nada en ningún servidor, no hay cuentas ni cookies. Las paletas que guardes se quedan en tu propio navegador.

Es un único archivo, `index.html`, sin dependencias. Código abierto bajo licencia MIT (ver `LICENSE`). Versión de prueba.

¿Ideas para mejorarlo? Escríbeme por Instagram o abre un *issue* aquí.
