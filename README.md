# Planner semanal

Herramienta gratuita de @psicofersaras para planificar la semana por bloques y llevarla a tu calendario (archivo .ics, compatible con Google Calendar, Apple Calendario, Outlook y otros).

Todo ocurre en tu navegador: no se envía ni se guarda nada en ningún servidor. Las paletas que guardes se quedan en tu propio navegador.

Versión de prueba.
